Smart QR Profile Platform - Starter (TypeScript)
--------------------------------------------------

This is a starter scaffold generated by ChatGPT (TypeScript) containing a minimal full-stack app:
- Frontend: Next.js (TypeScript) basic pages (/u/[qrCode], /login, /dashboard, /admin)
- Backend: Express (TypeScript) with simple APIs for QR logic
- PostgreSQL models (`pg`)
- .env.example for environment variables

How to run (local dev)
1. Backend
   cd backend
   npm install
   cp .env.example .env
   # fill DATABASE_URL and JWT_SECRET
   npm run dev

2. Frontend
   cd frontend
   npm install
   cp .env.local.example .env.local
   npm run dev

Notes:
- This is a starter scaffold. You need to configure PostgreSQL and Cloudinary if you use uploads.
- The code focuses on core flows: QR init, QR fetch, register/login, update (requires auth).

Migrating existing MongoDB data
1. Keep both connection strings in `backend/.env`:
   `DATABASE_URL=postgres://...`
   `MONGODB_URI=mongodb+srv://...`
2. Run:
   `cd backend`
   `npm run migrate:mongo-to-postgres`
3. After migration, the app only needs `DATABASE_URL` at runtime.
